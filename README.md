# 🎯 Lecteur de QR Code — Frédéric Salerno

Lecteur de QR code moderne développé en **React + Vite + Tailwind CSS**, avec prise en charge des formats **PNG / JPG / SVG** et **décodage intelligent** des données (Wi-Fi, URL, texte...).

![Logo](./public/splash-screen.png)

---

## ✨ Fonctionnalités

- 📷 Aperçu de l’image chargée (y compris SVG)
- 🧠 Lecture intelligente : Wi-Fi, lien, texte brut
- 🎨 Interface moderne (fond sombre, carte blanche)
- ⚙️ Stack : React, Vite, Tailwind CSS, jsQR, Canvg
- 🔒 Aucune donnée envoyée en ligne – tout est local
